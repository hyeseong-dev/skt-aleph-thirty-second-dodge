# 1분 피하기

방향키를 누르는 동안 플레이어가 부드럽게 움직이며, 떨어지는 물체를 피해 1분 동안 생존하는 브라우저 미니게임입니다.

## 실행

```bash
npm install
npm run dev
```

터미널에 표시된 로컬 주소를 브라우저에서 엽니다.

배포용 정적 파일은 `npm run build`로 생성합니다. Windows에서 발생하는 Node.js 24 종료 오류를 피하기 위해 빌드 명령은 Node.js 22를 사용합니다.

## 게임 방법

1. **게임 시작**을 누릅니다.
2. 방향키를 누르고 플레이어를 움직여 붉은 물체를 피합니다.
3. 충돌 없이 1분을 버티면 성공하고, 충돌하면 즉시 실패합니다.
4. 성공 후 다음 라운드에서는 장애물 생성 간격, 낙하 속도, 크기, 횡이동 폭이 단계적으로 증가합니다.

`Space` 키 또는 화면의 버튼으로 일시정지할 수 있습니다. 창을 벗어나면 게임이 자동으로 일시정지됩니다.

## 저장 항목

- 최장 생존 시간
- 누적 성공 횟수
- 음소거 설정
- 움직임 감소 설정

진행 중인 판은 저장하지 않습니다. 저장값이 없거나 손상된 경우 안전한 기본값으로 시작합니다.

## 난이도 검증

최종 기본 난이도는 사용자가 선택한 **800ms(B)**입니다. 비교 기준은 **900ms(A)**와 **800ms(B)**이며, 라운드 상승 공식과 다른 조건은 고정합니다. 구체적인 기록 방식은 `playtest-record.md`를 따릅니다.
